# 基础通用配置 (General)

本章节介绍 `clash-rs` 的基础入站端口监听、运行模式、网络绑定及运行环境相关字段。

---

## 常用入站端口

`clash-rs` 提供了最顶层的简写端口配置项。如果需要配置更丰富的身份认证或 TLS 特性，建议配合 [Listeners 入站监听器](/configuration/inbounds) 使用。

```yaml
port: 7890              # HTTP 代理端口
socks-port: 7891        # SOCKS5 代理端口
mixed-port: 7892        # HTTP + SOCKS5 混合代理端口
redir-port: 7893        # Linux TCP 重定向透明代理端口
tproxy-port: 7894       # Linux TProxy 透明代理端口
```

### 端口字段规格说明

| 配置字段 | 类型 | 是否必填 | 默认值 | 详细说明 |
| :--- | :--- | :--- | :--- | :--- |
| `port` | 整数 (1-65535) | 可选 | 无 (不开启) | 独立的 HTTP 代理服务端口。设置为 `0` 或省略则不启用。 |
| `socks-port` | 整数 (1-65535) | 可选 | 无 (不开启) | 独立的 SOCKS5 代理服务端口，同时支持 TCP 与 UDP。 |
| `mixed-port` | 整数 (1-65535) | 可选 | 无 (不开启) | 混合代理端口，单端口同时接受 HTTP CONNECT 隧道与 SOCKS5 握手。推荐桌面端首选。 |
| `redir-port` | 整数 (1-65535) | 可选 | 无 (不开启) | Linux TCP Redirect 重定向透明代理端口（需要 root 权限及 iptables 配合）。 |
| `tproxy-port` | 整数 (1-65535) | 可选 | 无 (不开启) | Linux TProxy 透明代理端口，同时支持 TCP 与 UDP（需要 root 权限及策略路由配合）。 |

## 网络绑定与认证

```yaml
allow-lan: false
bind-address: "127.0.0.1"
authentication:
  - "alice:secretpassword123"
  - "bob:anothersecret456"
```

### 字段规格说明

| 配置字段 | 类型 | 是否必填 | 默认值 | 详细说明 |
| :--- | :--- | :--- | :--- | :--- |
| `allow-lan` | 布尔值 | 可选 | `false` | 是否允许局域网（LAN）中的其他主机连接代理服务。设为 `false` 时仅本机可通过 127.0.0.1 访问。 |
| `bind-address` | 字符串 | 可选 | `"127.0.0.1"` | 代理入站服务绑定的网络接口 IP 地址。<br>• 填 `"*"` 或 `"0.0.0.0"`：监听所有 IPv4 网卡接口（会自动将 `allow-lan` 置为 `true`）；<br>• 填 `"::"`：监听所有 IPv6 网卡接口；<br>• 填 `"127.0.0.1"` 或 `"localhost"`：仅监听本机环回地址。 |
| `authentication` | 字符串列表 | 可选 | `[]` (无认证) | 基础代理接入认证（作用于 `port`、`socks-port`、`mixed-port`）。列表每项格式为 `"用户名:密码"`。未配置时无需密码即可连入。 |

## 运行模式 (`mode`)

控制 `clash-rs` 的全局流量路由调度逻辑：

```yaml
mode: rule
```

### 规格说明

- **类型**：枚举字符串
- **是否必填**：可选
- **默认值**：`rule`
- **可选枚举值全集**：

| 枚举值 | 大小写别名 | 说明 |
| :--- | :--- | :--- |
| **`rule`** (默认推荐) | `Rule` | **规则分流模式**。根据配置文件中的 `rules` 规则列表逐条匹配域名、IP、端口，精准决定直连还是走指定代理。 |
| **`global`** | `Global` | **全局代理模式**。无视分流规则，将所有经过代理的流量强制通过策略组中的节点发出。 |
| **`direct`** | `Direct` | **全局直连模式**。无视所有代理与策略组，所有网络连接直接通过本机物理网络发出。 |

## 日志输出控制 (`log-level`)

控制标准输出与控制台的日志打印详细程度：

```yaml
log-level: info
```

### 规格说明

- **类型**：枚举字符串
- **是否必填**：可选
- **默认值**：`info`
- **可选枚举值全集**：

| 枚举值 | 兼容别名 | 说明 |
| :--- | :--- | :--- |
| **`trace`** | 无 | 最详尽的底层网络追踪，打印所有网络包收发状态与协议细节（高并发下产生大量日志）。 |
| **`debug`** | 无 | 调试级别，打印每条连接的规则匹配命中过程、DNS 往返详情与节点握手。 |
| **`info`** (默认推荐) | 无 | 常规运行日志，打印核心组件初始化、监听启动及关键状态变更。 |
| **`warning`** | `warn` | 仅输出潜在异常与告警信息。 |
| **`error`** | 无 | 仅输出严重影响运行的致命错误。 |
| **`off`** | `silent` | 完全静默运行，不向标准输出打印任何运行日志。 |

## IPv6 与出站绑定

```yaml
ipv6: false
routing-mark: 6666
# interface: eth0
```

### 字段规格说明

| 配置字段 | 类型 | 是否必填 | 默认值 | 详细说明 |
| :--- | :--- | :--- | :--- | :--- |
| `ipv6` | 布尔值 | 可选 | `false` | 是否开启 IPv6 支持。当设为 `false` 时，本地 DNS 收到 AAAA（IPv6 地址）查询时将立即返回空应答。若物理网络环境无 IPv6，保持 `false` 可避免不必要的等待超时。 |
| `routing-mark` | 整数 (u32) | 可选 | 无 (0) | Linux 环境下出站数据包携带的路由标记 (`SO_MARK` / fwmark)。常用于在透明代理与 iptables / nftables 策略路由中配合使用，精准识别并放行 clash-rs 自身发出的流量，防止流量死循环。 |
| `interface` | 字符串 | 可选 | 无 (系统默认) | 强制绑定出站流量使用的物理网络接口名称（如 `eth0`、`en0`），实现指定网卡出站（`SO_BINDTODEVICE`）。 |

## QUIC 流量控制 (`quic`)

控制全局 QUIC 流量（目标端口为 UDP 443 的网络连接）的放行与阻断：

```yaml
quic: true                  # 允许 QUIC 流量（默认 true；设为 false 则直接阻断）
```

### 字段规格说明

| 配置字段 | 类型 | 是否必填 | 默认值 | 详细说明 |
| :--- | :--- | :--- | :--- | :--- |
| `quic` | 布尔值 | 可选 | `true` | **QUIC 流量总开关**（别名：`allow-quic`, `allow_quic`）。<br>• `true`（默认）：正常允许并转发 QUIC 流量。<br>• `false`：内核分流调度器在识别到目标端口为 `443` 的 UDP 数据报时立即就地切断阻断（Fast Cutoff）。<br>•该配置只影响通过clash-rs转发的流量，通过防火墙/TUN/eBPF等绕过clash-rs的直连流量不受此开关影响 |

::: tip 为什么需要禁用 QUIC？
1. **防止运营商 QoS 限速**：在国内许多宽带与移动网络环境中，运营商会对 UDP 流量进行较严重的带宽限速或随机丢包，导致 HTTP/3 (QUIC) 网页加载或 YouTube/B站 等视频播放出现卡顿。
2. **支持动态热切换**：该配置项不仅可以在配置文件中指定，还可通过 RESTful 控制接口（`PATCH /configs`）或官方 Web 控制面板概览页的 **QUIC** 开关随时一键切换，无需重启核心。
:::

## 实验性底层参数 (`experimental:`)

针对追求极致吞吐或运行在内存受限设备（如嵌入式软路由）的高级用户，`clash-rs` 提供了底层内存与缓冲区控制：

```yaml
experimental:
  tcp-buffer-size: 65536      # TCP 双向转发单流缓冲区大小（字节）
```

| 字段 | 类型 | 是否必填 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| **`tcp-buffer-size`** | 整数 (字节) | 可选 | `65536` (64KB) | TCP 流双向复制时分配的中间缓冲区字节数。调大有助于提高千兆/万兆带宽吞吐，调小可降低单连接内存占用。 |
